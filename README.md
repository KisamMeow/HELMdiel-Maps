# HELMdiel-Maps
Maps for the HELM system on FFXI, specifically for the HorizonXI server. These are based on the 2048x2048 maps from remapster, downscaled to 1024x1024 with a box filter. Some maps are from FFXI-Atlas.com and some are vanilla maps, all maps are scaled to 1024.

To use these maps place them in your pivot folder, these maps only have HELM points on them so you may want to only use them while harvesting then unload them when you are done if you want to have the extra stuff you might have from other maps.

Original maps by akaden and the remapster team at https://remapster.com/.

Find more information on that project at https://www.reddit.com/r/ffxi/comments/gmxv3a/introducing_the_ffxi_remapster_project/

I've made these maps with GIMP and TexHammer.
